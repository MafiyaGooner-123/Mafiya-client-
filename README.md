# Mafiya Client (Fabric 1.21.11)
Joke "hack client" mod by MafiyaGooner. Press **Right Shift** (or type `/mafiya`) to open the big GUI.
It contains no real hacks.

## Build the jar
**GitHub (no PC needed):** upload this folder to a new GitHub repo -> Actions tab -> run "build" -> download the `mafiya-client` artifact (the jar inside).
**PC:** install Java 21 + Gradle 9, then run `gradle build`. Jar: `build/libs/mafiya-client-1.0.0.jar`.
Put the jar (and Fabric API for 1.21.11) in your `mods` folder.
